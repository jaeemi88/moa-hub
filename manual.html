처음 한 번만

기기(휴대폰·PC)마다 허브에서 각 앱을 한 번씩 눌러 들어가면 준비가 끝납니다.

  1. 원장님께 받은 승인 링크 누르기

    허브가 열리면서 그 기기에 강사 정보가 저장돼요. 기기(휴대폰·PC)마다 한 번씩 눌러 주세요.

  2. 허브를 홈 화면에 추가

    moa-hub.vercel.app — 앱처럼 바로 열 수 있어요. 다음부터는 첫 화면에서 강사만 누르면 돼요.

  3. 허브에서 앱을 하나씩 눌러 들어가기

    앱이 내 강사 코드를 그 기기에 기억해요. 다음부터는 주소만으로 열어도 코드를 묻지 않아요.

  4. 운영보드를 열 때 접속 암호 한 번 입력

    한 번 넣으면 그 기기에서 기억해요.

  5. 돌아갈 땐 맨 위 ← 허브

    모든 앱 맨 위 네이비 줄에 있어요.

서류 탭이 주황·빨강이면 첫 강사료 지급 전까지 신분증·통장 사본을 받으세요.
강사 등록 화면 맨 위 ① 기본 정보 ~ ⑤ 동의 버튼을 누르면 그 칸으로 바로 이동하고, 내리면 버튼 줄이 위에 고정돼 따라와요. 생년월일은 년·월·일 선택 칸으로 고릅니다.

자주 헷갈리는 것

질문을 누르면 답이 펼쳐져요.

앱이 강사 코드를 입력하라고 해요
코드 없는 주소로 열었을 때예요. 허브 버튼으로 한 번 들어가면 그 기기에서 기억해요.
들어갔는데 전부 0이에요
오른쪽 위 코드 철자를 확인하세요 (예: jinromoa ↔ jiromoa). 허브 버튼으로 다시 들어가면 맞는 코드로 열려요.
업데이트했는데 화면이 예전 그대로예요
1~2분 기다린 뒤 새로고침하세요. PC는 Ctrl + Shift + R, 휴대폰 홈 화면 앱은 완전히 껐다 켜기.
신규 강사 신청은 어디서 봐요?
준비현황 오늘 할 일의 "신규 강사 신청 N명 · 확인하기" › 파트너강사 탭. 카드를 열어 강사료·평점 입력 후 저장하면 등록 완료예요.
강사가 서류 없이 신청했어요
성명·연락처·동의만 필수예요. 강사 카드에 "서류 미제출"로 표시되니, 첫 강사료 지급 전까지 받으면 됩니다.
학생이 입장 코드가 안 된대요
① 코드 4자리를 다시 확인 ② 코드의 사용 기간이 끝났는지 허브 강의 입장 코드 카드에서 확인 — 목록에 없으면 끝난 거예요. 코드 만들기로 새로 만들어 알려 주세요.
학생이 "15분 동안 잠겼다"고 해요
같은 인터넷(교실 와이파이 등)에서 틀린 코드가 30번 넘게 들어오면 코드 추측을 막으려고 15분간 잠겨요. 코드를 칠판에 크게 적어 주고, 휴대폰 데이터로 바꿔서 입장하게 하면 바로 들어갈 수 있어요.
예전 학생 결과가 목록에서 사라졌어요
30일 자동 삭제 때문이에요. 지워진 자료는 되돌릴 수 없어요. 앞으로 남길 결과는 30일 안에 워드로 저장하거나 조회 기간 연장을 해 두세요.
모의면접 결과에 "다시 말해보기" 버튼이 없어요
강사용 설정의 다시 답변하기가 "재도전 불가"로 되어 있으면 숨겨져요. 강사용으로 연 화면에서도 보이지 않는 게 정상이에요.
학생 이름·숫자 4자리는 어디에 저장되나요?
허브에서 입력한 이름·숫자 4자리는 학생 기기에만 잠깐 보관되고 창을 닫으면 지워져요. 서버로는 입장 코드만 확인해요. 자세한 내용은 학생 입장 화면의 개인정보처리방침에 있어요.
학생이 결과 코드를 잃어버렸어요
자소서 강사용 › 완료된 첨삭 › 학생에게 다시 보내기. 기간이 끝났으면 조회 기간 연장 먼저 하세요.
학생 전공이 목록에 없어요
모의면접 강사 설정 › 오늘 수업 › 전공·직무 선택 방식을 프리셋 + 직접 입력으로 바꾸세요. 학생이 적은 전공에 맞춰 AI가 질문 6개와 기준을 만들어요.
고등학생 반인데 지원 기업 칸이 보여요
모의면접 오늘 수업과 자소서 알림 설정에서 기업 분석 수준을 끔으로 바꾸고 학생에게 새로고침을 부탁하세요.
"기업 정보를 검색하지 못했어요"가 떠요
잠시 뒤 다시 누르면 대부분 해결돼요. 계속되면 화면을 캡처해 원장님께 보내 주시고, 그동안은 기업 분석을 기본으로 두고 수업하세요.
QR 결과를 불러왔는데 응답이 없대요
트래커에서 그 프로그램에 응답이 들어왔는지 확인하고, 주소를 다시 복사해 붙여넣으세요.
결과보고서의 교육 환경·추천 의향 점수가 비어요
QR 설문에 없는 항목이에요. 기관 설문 결과가 있을 때만 직접 입력하세요.
지난 강의 카드의 교안·대본이 흐리게 보여요
강의가 끝나 필요 없어진 항목이라 알림을 멈춘 거예요. 정상입니다.
편집 모드에서 항목이 빨간 ×로 보여요
누르면 삭제돼요. 편집 끝을 누른 뒤 체크하세요.

설정 도움말

자소서·모의면접 강사 화면의 설정이 무엇을 바꾸는지 정리했어요. 앱에서 ?를 누르면 해당 항목이 바로 펼쳐져요.

먼저 기억할 것 하나. 아래 설정은 모두 자소서 앱과 모의면접 앱이 따로예요. 두 앱을 같이 쓰는 날은 양쪽 모두 확인하세요. (강사 명부·승인 링크만 두 앱이 함께 써요)
새 검수 요청 이메일 알림
학생이 검수를 요청하면 이 주소로 메일이 와요. 대기함에 매번 들어가 보지 않아도 돼요.
· 자소서: 알림 설정 › 이메일 칸 › 저장하기 (칸마다 따로 저장)
· 모의면접: 오늘 수업 › 알림 이메일 (바꾸는 즉시 저장, "강사 검토 후 전달"일 때만 와요)
메일이 안 오면 ① 저장하기를 눌렀는지 ② 스팸함 ③ 주소 철자를 확인하세요.
재도전 허용 범위 · 다시 답변하기
한 학생이 몇 번까지 다시 제출할 수 있는지 정해요. 같은 휴대폰·브라우저 기준이에요.
· 자소서: 자유롭게 / 최대 2번 / 1번만
· 모의면접: 자유롭게 / 1회만 재도전 / 재도전 불가 (재도전 불가면 결과의 다시 말해보기가 숨겨져요)
집체교육은 자유롭게, 1:1 코칭은 1번(1회)만을 추천해요.
기관명 · 여러 기관 동시 운영
기관명이 있어야 승인할 때 트래커 기관별 실적·만족도 설문 버튼이 함께 움직여요. 비어 있으면 셋 다 나타나지 않고, 넣은 뒤 제출분부터 적용돼요(소급 안 됨).
· 자소서: 알림 설정 › 기관명 하나, 또는 여러 기관 동시 운영에 등록해 두면 학생이 소속을 골라요
· 모의면접: 오늘 수업 › 기관명 (전공 패키지에 기관명을 넣으면 그 패키지를 고른 학생에게 우선 적용)
센터 강의는 허브의 강의 입장 코드로 들어오면 원장님 통계에 자동으로 묶여요.
학생 결과 조회 기간
집체교육 학생이 결과 링크를 볼 수 있는 날 수예요(보통 5~7일). 트래커에 등록된 1:1 코칭 학생은 기간 제한이 없어요. 기간이 지난 학생은 자소서 완료된 첨삭 › 조회 기간 연장 › 학생에게 다시 보내기. 자료는 기간이 끝나고 30일 뒤 자동 삭제되니 남길 결과는 워드로 저장하세요.
제출 방식 (모의면접)
바로 AI 피드백은 학생이 답하자마자 피드백을 받는 연습용, 강사 검토 후 전달은 강사님이 확인하고 승인해야 학생에게 가는 1:1 첨삭용이에요. 승인하면 학생 폰의 📬 내 결과함에 자동으로 도착해요.
전공·직무 선택 방식 (모의면접, 10.5)
학생 첫 화면에 무엇을 보여 줄지 정해요.
· 프리셋만: 체크한 전공 카드만 (한 학과 수업)
· 프리셋 + 직접 입력: 카드 아래 ✏️ 직접 입력 칸 추가
· 직접 입력만: 지원처가 제각각인 캠프·개인 코칭
학생이 적은 전공·직무·기업에 맞춰 AI가 질문 6개와 채점 기준을 만들어요. 수업 뒤 키워드 TOP에서 자주 나온 것을 전공 패키지로 추가하면 정식 목록에 들어가요.
기업 분석 수준 (두 앱 각각, 10.5)
지원 기업 정보를 얼마나 깊게 쓸지 정해요.
· 끔: 지원 기업 칸·질문이 사라져요 — 고등학생, 1회성 특강
· 기본: 지금까지와 같아요. 업종 수준으로만 반영, 검색 없음 — 일반 대학 수업
· 심화: 인재상·최근 이슈를 실시간 검색해 카드로 보여 주고 질문·피드백에 반영 — 취업 직전 반
위치: 모의면접 오늘 수업, 자소서 알림 설정(고르는 즉시 저장). 네이버 유료 고객은 설정과 관계없이 늘 심화예요. 같은 기업은 7일 저장해 다시 써요(새 기업 1곳 약 50~100원).
