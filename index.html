제안서 생성기
학교명만 입력하면 A4 제안서 자동생성(3단계 구성), 기본값 편집 가능, 인쇄/PDF 저장
나의 시간 설계도
로그인 없이 QR로 바로 접속(moa-timeplan.vercel.app), 졸업까지 남은 주·자유시간 자동 계산, 매주 반복 타임블록·점검 루틴(주간·월간·학기 말)을 구글·아이폰·삼성 캘린더에 등록, 입력값 저장 안 함
자주 헷갈리는 부분
· "제출"은 질문 하나씩, "강사에게 넘기기"만 선택 가능
· 재도전·기업 분석 수준 설정은 두 앱 각각 따로 설정해야 함 (고등학생은 끔, 취업 직전 반은 심화)
· 만족도 설문은 기관명을 넣어야만 나타남 (소급 적용 안 됨)
· 강사 알림 이메일은 "개별 저장" 버튼을 따로 눌러야 함
· 학생은 강의 입장 코드가 있어야 허브에 들어옴 (강의 전 허브 맨 위 카드에서 만들기)
· 자소서·모의면접 자료는 30일 뒤 자동 삭제 — 남길 결과는 워드로 저장
